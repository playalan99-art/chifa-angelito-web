# CHIFA ANGELITO - Página web

## 1. Instalar Python
Instala Python 3.11 o superior.

## 2. Abrir la carpeta
Abre una terminal dentro de esta carpeta.

## 3. Instalar Flask
```bash
pip install -r requirements.txt
```

## 4. Ejecutar
```bash
python app.py
```

## 5. Abrir la página
En el navegador entra a:

http://127.0.0.1:5000
